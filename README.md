# Анализ временного ряда энергопотребления PJME

## Описание проекта

Целью проекта является исследование временного ряда почасового энергопотребления региона PJME и сравнение различных подходов к прогнозированию временных рядов.

В рамках проекта выполняются:

* предварительный анализ данных (EDA);
* исследование сезонности и стационарности;
* применение статистических методов прогнозирования;
* применение методов машинного обучения;
* применение методов глубокого обучения;
* выявление аномалий;
* разработка пайплайна прогнозирования временного ряда.

---

## Описание набора данных

Используемый датасет: **PJM Hourly Energy Consumption**.

Исследуемый временной ряд содержит данные о почасовом потреблении электроэнергии в регионе PJME.

Целевой признак:

* **PJME_MW** — потребление электроэнергии (МВт).

Основные характеристики набора данных:

* период наблюдений: с 01.01.2002 по 03.08.2018;
* количество наблюдений: 145 366;
* частота наблюдений: почасовая;
* пропущенные значения отсутствуют.

# Задача №1. Подготовка данных и EDA

## Подготовка данных

Временная метка `Datetime` была преобразована в формат `datetime` и установлена в качестве индекса временного ряда.

В ходе анализа качества данных установлено:

* пропущенные значения отсутствуют;
* типы данных корректны;
* временной ряд подготовлен к дальнейшему анализу.

---

## Анализ временного ряда

### Общая характеристика

Исследуемый временной ряд содержит данные о почасовом энергопотреблении за период более 16 лет.

Визуальный анализ показал наличие выраженной сезонности и циклических колебаний.

### Суточная сезонность

Минимальное энергопотребление наблюдается в ночные часы (03:00–05:00).

Максимальное энергопотребление наблюдается в вечерние часы (18:00–20:00).

### Недельная сезонность

В будние дни энергопотребление остается относительно стабильным.

В выходные дни наблюдается заметное снижение нагрузки на энергосистему.

Минимальное потребление фиксируется в воскресенье.

### Годовая сезонность

Максимальные значения энергопотребления наблюдаются в летние месяцы (июль–август).

Минимальные значения наблюдаются весной и осенью.

Полученные результаты свидетельствуют о наличии выраженной годовой сезонности.

---

## Проверка стационарности

Для оценки стационарности временного ряда был использован тест Дики-Фуллера (ADF Test).

Результаты теста:

* ADF Statistic = -18.83;
* p-value = 2.02 × 10⁻³⁰.

Поскольку значение p-value значительно меньше уровня значимости 0.05, нулевая гипотеза о нестационарности была отвергнута.

Несмотря на наличие выраженных сезонных колебаний, временной ряд демонстрирует статистические признаки стационарности.
