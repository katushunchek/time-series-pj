## Анализ временного ряда энергопотребления PJME

Целью проекта является исследование временного ряда почасового энергопотребления региона PJME и сравнение различных подходов к прогнозированию временных рядов.

В рамках проекта выполняются:

предварительный анализ данных (EDA)
исследование сезонности и стационарности
применение статистических методов прогнозирования
применение методов машинного обучения
применение методов глубокого обучения
выявление аномалий
разработка пайплайна прогнозирования временного ряда

Используемый датасет: PJM Hourly Energy Consumption

Исследуемый временной ряд содержит данные о почасовом потреблении электроэнергии в регионе PJME

Основные характеристики набора данных:

период наблюдений: с 01.01.2002 по 03.08.2018
количество наблюдений: 145 366
частота наблюдений: почасовая
пропущенные значения отсутствуют

Основной задачей исследования является построение моделей прогнозирования энергопотребления на основе исторических данных.

Для достижения поставленной цели необходимо:

1. Выполнить предварительный анализ временного ряда
2. Выявить наличие тренда и сезонности
3. Исследовать стационарность временного ряда
4. Сравнить статистические методы прогнозирования
5. Сравнить методы машинного обучения
6. Сравнить методы глубокого обучения
7. Разработать автоматизированный пайплайн прогнозирования
8. Оценить качество моделей прогнозирования

Задача №1. Подготовка данных и EDA

Временная метка `Datetime` была преобразована в формат `datetime` и установлена в качестве индекса временного ряда.

В ходе анализа качества данных установлено:

Пропущенные значения отсутствуют
типы данных корректны
временной ряд подготовлен к дальнейшему анализу

Исследуемый временной ряд содержит данные о почасовом энергопотреблении за период более 16 лет

Визуальный анализ показал наличие выраженной сезонности и циклических колебаний.

Минимальное энергопотребление наблюдается в ночные часы (03:00–05:00).

Максимальное энергопотребление наблюдается в вечерние часы (18:00–20:00).


В будние дни энергопотребление остается относительно стабильным. В выходные дни наблюдается заметное снижение нагрузки на энергосистему.Минимальное потребление фиксируется в воскресенье.

Максимальные значения энергопотребления наблюдаются в летние месяцы (июль–август). Минимальные значения наблюдаются весной и осенью. Полученные результаты свидетельствуют о наличии выраженной годовой сезонности.

Для оценки стационарности временного ряда был использован тест Дики-Фуллера (ADF Test).

Результаты теста:

* ADF Statistic = -18.83;
* p-value = 2.02 × 10⁻³⁰.

Поскольку значение p-value значительно меньше уровня значимости 0.05, нулевая гипотеза о нестационарности была отвергнута. Несмотря на наличие выраженных сезонных колебаний, временной ряд демонстрирует статистические признаки стационарности.

Задача №2. Статистические методы прогнозирования

В рамках исследования были рассмотрены следующие статистические модели:

 Модель               MAE 

 Prophet          4214.99 
 Seasonal Naive   4958.48 
 Naive            6535.57 
 Theta            6836.97 
 ETS              9217.10 
 ARIMA(1,1,1)    12894.66 

Лучшую точность показала модель Prophet с ошибкой 4214.99 МВт. Модель Seasonal Naive продемонстрировала высокую эффективность благодаря выраженной суточной сезонности исследуемого временного ряда.

На основании сравнения моделей Prophet была выбрана как лучшая статистическая модель для дальнейшего использования.

Задача №3. Методы машинного и глубокого обучения

В рамках задачи были построены модели машинного обучения, нейросетевые модели и методы выявления аномалий.

Методы Z-score и Isolation Forest показали близкие результаты, тогда как IQR оказался более чувствительным и выявил больше аномальных наблюдений.

Итоговый вывод: среди всех рассмотренных data-driven подходов наилучшее качество прогнозирования показала модель XGBoost с MAE = 1770.91.

Задача №4. Разработка пайплайна прогнозирования

Для автоматизации решения задачи прогнозирования был разработан пайплайн `src/pipeline.py`.

Пайплайн включает следующие этапы:

1. загрузка подготовленного датасета;
2. преобразование временной метки;
3. создание календарных и лаговых признаков;
4. разделение данных на обучающую и тестовую выборки;
5. обучение модели XGBoost;
6. оценка качества модели по метрике MAE.

В качестве итоговой модели была выбрана XGBoost, так как она показала наилучшее качество среди всех рассмотренных моделей.

Результат тестирования пайплайна:
